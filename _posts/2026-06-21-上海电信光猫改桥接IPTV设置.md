## 引言

中央广播电视台签约FIFA世界杯，为IPTV狠狠引了一波流。除了IPTV以外，基本没有路径可以在电视上看世界杯。如果家里光猫上网设置是路由模式的话，宽带师傅是可以帮你搞定IPTV业务的；但是一旦你为了局域网设施把光猫上网设置改为桥接的话，装修师傅就青黄不接了。这也是一个相当“老生常谈”的问题。 **仅限上海电信** ，本文经过验证，光猫在桥接模式下，IPTV也是可以正常通过认证的。

**声明：本教程系个人经验，仅供参考，非官方操作或教程，不懂计算机网络不要轻易尝试**

设备情况：

光猫F450g、路由器Xiaomi WR30U、送的IPTV盒子、网线若干。

线路情况：

IPTV盒子连接光猫、路由器连接光猫。

## 原理

B面认证需要IPTV盒子接入特殊的专网（vlan），而上海电信设置的是vlan85。在光猫上网设置-路由模式下，设置好vlan绑定后，IPTV盒子接在光猫3号、4号Lan口，IPTV就能正常通过B面认证。在此基础上，不动物理连接，将光猫上网设置直接改为桥接模式，IPTV的B面认证仍然可以通过，但是A面认证无法通过，证明 **专网连接与上网模式无关** 。

A面认证就是正常的互联网连接。在路由模式，光猫所有Lan都是有网络的；但是改为桥接之后，光猫本身没有网络连接，无法过A面认证。网络上有常见的软路由VLAN划分方法，是通过路由器伪装B面认证，让IPTV盒子接在路由器Lan侧联网，过A面认证。这里有个误区，很多人会像给IPTV打vlan一样，尝试在光猫给上网打上vlan单线复用。但上海电信上网是没有vlan的，光猫如果上网打上vlan直接无法拨号。

不妨换一种思路，或者说相当自然的思路：既然B面认证可以过，那只要让光猫端口能联网不就可以了？当然不可以多拨号，这是不可能的。但是，只要把路由器的网络“引回”光猫，让光猫作为傻瓜交换机，就可以做到过A面认证了。这种操作不需要改路由器的网卡、防火墙等等配置，简单好用。

## 改桥接（写给想改桥接的，和觉得桥接改的不对的）

如果你的光猫上网还处于路由模式，那么可以试着改为桥接模式，路由器拨号。首先，需要拿到超级管理员的密码。这里我就直接引用他人文章了：[中兴电信光猫F450G V2超级密码](https://www.cnblogs.com/gkmin/p/18304177)，具体的光猫型号有所差别，请自己确认。

连接光猫WIFI，或者物理连接，然后访问管理页面 `192.168.1.1`，用户名 `telecomadmin`，密码就是获取到的密码。注意，每个光猫的超级密码都不一样，而且，电信那边刷新配置缓存等等操作后，也会 **刷新超级密码** 。建议保存好光猫超级密码获取方式，因为光猫不变，获取的办法也是不变的。

在光猫中，网络-网络设置里，建议先截图保存路由模式的配置，方便自己改回来。保存后，删除所有路由模式的网络连接。新建网络，业务选择上网，连接模式为桥接，封装还是PPPOE，IP可以选择IPV4&IPV6，后面的vlan和端口一个也不要选。保存之后，再添加一个连接，业务选择其它，连接模式选择桥接，封装还是PPPOE，IP选择IPV4，启用vlan，填写编号85，802.1p选择5，后面的端口一个也不要选。之后转到左侧目录中vlan绑定，把所有端口用户侧vlan85绑定到3_Other_B_VID_85（刚创建的其它业务连接，其实就是IPTV）。

然后到应用-IGMP中， **关闭所有IGMPSnooping** ，设置3_Other_B_VID_85组播vlan为51并保存。

现在已经可以从路由器拨号了。

### 光猫调整

除了以上基本的连接配置修改，如果你需要像本文一样把光猫变成交换机，还要做这些事： **必须关闭光猫的DHCP功能** ，否则网络内同时存在两个DHCP服务器，内网直接爆炸； **必须设置光猫和路由器网段不同** ，一般光猫是`192.168.1.1`网段，路由器不能选择`192.168.1.x`，否则造成环路，内网还是直接爆炸。

所以，我会在路由器openwrt系统内修改`/etc/config/network`，添加如下配置：

```
config interface 'wanonu'
        option proto 'static'
        option device 'eth1'  #填写你的路由器wan网卡
        option ipaddr '192.168.1.11'
        option netmask '255.255.255.0'
        option metric '10'
```

同时修改防火墙`/etc/config/firewall`：

```
config rule
        option name 'Allow-Modem-Access'
        option src 'lan'
        option dest 'wan'
        option dest_ip '192.168.1.1'
        option target 'ACCEPT'

config nat
        option name 'SNAT-Modem'
        option src 'lan'
        option dest 'wan'
        option dest_ip '192.168.1.1'
        option target 'SNAT'
        option snat_ip '192.168.1.11'
```

使得路由器联网设备可以直接访问`192.168.1.1`进行管理。

## 接线

光猫lan1口是默认千兆端口，直接接路由器的wan，然后在路由器内进行拨号。不知道宽带账号和密码的向师傅要就行，这种基本的还是很轻松就能要到的。

光猫lan2口虽然写着itv，实际和iptv一点关系也没有，就是正常的百兆端口。我们把路由器的一个lan口用网线和光猫lan2口连接，使得光猫其它lan口可以获得路由器DHCP服务。

光猫lan3、lan4就是iptv可以使用的端口了。我将IPTV盒子插在4号口。不出意外，光猫详情页面会显示2号口和4号口都有连接，且速度都是100M。

## 启动

现在打开盒子，一般认证就通过了，可以正常观看、回看。如果播一会就断开，请在光猫检查端口协商速率，要一致，应该都是100M。
